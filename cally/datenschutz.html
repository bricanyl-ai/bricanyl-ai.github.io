Datenschutzerklärung

Stand: 7. Oktober 2026

1. Worum es geht

Cally ist ein privates Desktop-Widget für Windows. Diese Erklärung beschreibt, welche Daten Cally verarbeitet, wenn es mit einem Google-Konto verbunden wird.

2. Verantwortlich

Verantwortlich ist der Betreiber dieses privaten Projekts. Kontakt: github.com/bricanyl-ai.

3. Zugriff auf Google-Daten

Nur nach ausdrücklicher Zustimmung im Google-Anmeldefenster greift Cally auf folgende Daten zu:

  • Google Tasks (https://www.googleapis.com/auth/tasks): Aufgaben lesen, anlegen, ändern, als erledigt markieren und löschen, um sie im Widget anzuzeigen und mit dem Smartphone abzugleichen.
  • Von Cally erstellte Kalender (https://www.googleapis.com/auth/calendar.app.created): Cally legt einen eigenen Kalender „Cally Erinnerungen“ an und verwaltet darin Erinnerungstermine für Aufgaben mit Uhrzeit. Auf andere Kalender hat Cally keinen Zugriff.

Cally greift nicht auf E-Mails, Kontakte, andere Kalender, Google Notizen selbst oder sonstige Daten zu.

4. Wo die Daten verarbeitet werden

  • Die Verarbeitung findet ausschließlich lokal auf dem PC statt, auf dem Cally läuft.
  • Cally betreibt keine eigenen Server. Daten werden nur direkt zwischen dem PC und Google ausgetauscht.
  • Eine Weitergabe an Dritte, Analyse, Tracking oder Werbung findet nicht statt.
  • Aufgaben werden als lokale Datei zwischengespeichert. Die Google-Zugangsdaten (Tokens) werden mit der Windows-Datenschutz-API (DPAPI) verschlüsselt gespeichert.

5. Google API Services User Data Policy

Die Nutzung und Weitergabe von Informationen, die Cally von Google-APIs erhält, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Cally's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Widerruf und Löschung

  • Der Zugriff kann jederzeit in Cally („Google-Verbindung trennen“) oder unter myaccount.google.com/permissions widerrufen werden.
  • Lokale Daten werden gelöscht, indem der Cally-Datenordner gelöscht wird (%APPDATA%\Cally bzw. Cally-Daten neben der portablen Version).
  • Der Kalender „Cally Erinnerungen“ kann im Google Kalender gelöscht werden.
